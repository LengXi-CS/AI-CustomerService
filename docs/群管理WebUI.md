# 配置 WebUI（配置、运行状态与聊天记录）

群管理提供群列表、搜索与模式筛选、新增／编辑／移除群、全局群处理开关、修改对比及安全保存。回复策略提供安抚话术、回复节奏、路由阈值与负责人通知配置；模型与连接提供模型、FastGPT、GeWe、飞书设置以及连接测试。

运行状态提供服务启动时间、运行时长、调度器状态、本地数据库读取检查、待重启配置数量、任务统计与最近异常摘要。

修改记录与恢复提供保存／恢复操作记录、历史备份列表、差异预览和确认恢复。

聊天记录提供已归档群列表和聊天气泡，复现客户、客服与机器人的消息、引用和仍保留在本地的附件。

页面已根据项目提供的 Handsin 视觉规范统一适配，使用正式 Logo、薄荷青渐变、白色卡片与森林登录背景。设计参数、资源来源和维护方式见 [WebUI 视觉适配](WebUI视觉适配.md)。

## 首次启用

本工作区的前端已经构建好，不必再次运行 pnpm。直接回到项目根目录设置密码：

```powershell
cd D:\瀚思AI客服
.venv\Scripts\python.exe scripts/setup_admin.py
```

首次克隆项目、前端有修改或构建文件缺失时，在项目根目录执行：

```powershell
uv sync --extra dev
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_webui.ps1
```

构建脚本优先使用 PATH 中的 Node.js 和 pnpm，也会尝试本机 Codex 的捆绑运行时，因此不需要手工修改系统 PATH。也可以传入 `-NodePath`、`-PnpmPath` 指定工具的绝对路径。其他机器如果没有这些工具，需要安装 Node.js 22.12 或更新版本及 pnpm 11；已经包含前端资源的 Python wheel 则不需要 Node.js。

密码交互输入且不回显，至少 6 个字符。凭证只保存加盐 scrypt 摘要，默认位置为 `data/admin/auth.json`，不进入 Git。也可以用 `ADMIN_AUTH_PATH` 指定位置。服务账户需要读取凭证，并能写入群策略文件与备份目录；不要把整个 `data/` 目录开放给其他账户。

前端构建输出到 `src/fastgpt_assistant/server/admin_static/`。生产运行只需要 Python，不需要启动 Node/Vite。构建文件被 Git 忽略；新机器需要构建一次，或者使用已经包含前端资源的 Python wheel。制作 wheel 前先执行前端构建。

已有 Windows 服务需要重启一次来加载新增 Python 模块。先检查待处理任务及附件投递情况，再在管理员 PowerShell 使用：

```powershell
.\scripts\restart_app.ps1
```

访问 `http://127.0.0.1:5330/admin/`。以后修改群策略无需重启，首次新增 WebUI 模块需要重启。

## 使用流程

1. 使用本机设置的密码登录。
2. 添加或编辑群。群 ID 从回调日志的 `chat` 字段获取，应以 `@chatroom` 结尾。既有群 ID 不允许在编辑表单中改写；需要更换时先新增新群，再移除旧群。
3. 新群默认停用，并要求客户 @机器人。按需调整策略；可以先设置影子观察，再正式启用。
4. 负责人从回调日志的 `sender` 字段获取，运行时自动视为客服。其他客服 ID、机器人昵称每行填写一项。
5. 点击“加入待保存修改”只更新页面草稿。点击“查看并保存”，核对差异后确认，才写入原 TOML。
6. 保存成功表示文件已更新；下一次消息处理或调度流程读取群策略时生效。页面不会声称已经处理了一条真实微信消息。

全局开关关闭时所有群暂停处理；全局开关开启后，各群继续按自身模式处理。影子模式不向该群发送机器人回复。群策略不改变已有任务隔离、人工接管及附件串行发送规则。

群编辑提供“引用原问题回复”和“同一事项只回复一次”，均默认关闭。前者为安抚和澄清引用原文本；后者在调度前关联同一客户的说明、附件和补充需求，并持久化安抚状态。关联不确定时保留独立需求；不同订单和不同主题分别处理。两项目前仅在 AI客服测试（外部）启用，生产群验收后再逐群开启。首次安装相关后端代码需要重启；随后修改开关沿用配置热加载。

## 保存、冲突与恢复

### 回复策略

侧栏选择“回复策略”。小屏幕使用页面顶部的切换按钮。切换页面会保留草稿；关闭页面或退出时，存在未保存修改会提示。

- **安抚话术**：固定／模型模式及固定文案单独保存到群策略 TOML，下一次读取群策略时生效，无需重启；固定模式文案不能为空。
- **回复节奏与路由**：静默等待时间、轮询间隔、附件发送间隔、正常回复阈值、人工阈值、负责人通知单独保存到 `.env`，必须重启服务才生效。
- 两个区域分别确认、分别保存。保存某一区域不会丢弃另一区域的草稿，也不会写入其他群策略或凭证。
- 页面同时显示配置值和服务启动时读取的“当前运行”值；不一致的参数标为“待重启”，刷新页面后仍保留此状态。服务重启后重新加载，数值相同则显示“运行值一致”。
- 如果服务环境变量覆盖某个参数，该参数显示为只读，并列出来源键；页面修改 `.env` 无法覆盖服务环境变量。需在实际服务环境中修改，并重启服务。
- 正常回复阈值也作为结构化查询的信息完整度门槛。意图置信度和信息完整度仍分别处理，路由判断的既有顺序不变。
- 范围：静默等待时间为非负整数，轮询间隔至少 1 秒，附件间隔非负，三类时间参数均不超过 86400 秒（24 小时），`0 ≤ 人工阈值 ≤ 正常回复阈值 ≤ 1`。静默等待时间允许设置为 0。
- `.env` 保存只开放上述六项；保留所有其他字段、注释、未知项和换行。已有新旧别名及重复赋值会一起更新，避免别名优先级导致保存无效。
- `.env` 原文件可能含凭证，备份保存在 `data/admin/reply-backups/`（随管理员凭证父目录变化），不要分享、提交或公开该目录。恢复时在本机复制所选备份回 `.env`，然后重启服务。
- 安抚话术和群管理共用同一个 TOML 版本检查：其他页面或人工修改了文件会拒绝旧版本保存，保留当前页面草稿，重新加载前请记录需要保留的修改。

新增回复策略后端模块同样需要**重启一次** Windows 服务，然后刷新页面。前端构建已完成时，无需重新设置管理员密码。旧进程尚未加载新接口时，页面会明确提示重启，不会把 404 当作保存成功。

### 群管理

- 每次读取返回原文件的 SHA-256 版本。保存时必须携带这个版本；其他浏览器或人工修改了文件，会返回 409，拒绝覆盖。
- 冲突发生时页面保留未保存修改，提示重新加载；当前版本没有自动合并。重新加载前请记录需要保留的改动。
- 编辑使用 TOML Kit，保留已有群的注释、未知字段以及未在页面开放的全局话术配置。
- 写入前备份原文件，备份成功后用同目录临时文件原子替换。默认备份位置是 `data/admin/group-backups/`，随 `ADMIN_AUTH_PATH` 的父目录变化。
- 如需恢复，选择一个备份，在本机将其复制回 `config/wechat_groups.toml`，然后重新加载页面。恢复同样走既有热加载机制。
- 本阶段按现有部署方式使用单个 Uvicorn worker。会话和写入锁保存在进程内，不要同时启动多个管理服务写入同一个配置文件。

### 模型与外部服务连接

侧栏选择“模型与连接”，也可以访问 `/admin/#connections`。配置服务地址、模型名称、知识库 ID、GeWe 实例 ID 和飞书表格来源。

- 四项密钥分别提供“保留／替换／清除”。保留不需要输入原密钥；替换时填写新值；清除会在 `.env` 写入空值。不会把占位符当作密钥保存。
- API 不返回已保存的密钥，修改对比只显示操作，不显示新旧内容。密钥由服务环境变量提供时为只读。
- 保存沿用现有新旧别名；更新已有所有别名与重复赋值，保留其他参数、未知字段、注释与换行。新字段使用当前标准键名。
- 飞书同步脚本已统一通过 Settings 读取凭证，支持 `LARK_*` 与历史 `EA_LARK_*` 名称。脚本下次执行即读取新文件；客服服务中的连接客户端需重启才使用新配置。
- FastGPT 的旧兼容密钥仍按既有规则兜底。页面会提示兼容密钥是否存在；清除应用 API Key 不代表同时清除了兼容密钥。本页不编辑 root key 或保险库密钥。
- 回复策略和连接配置共用一个 `.env` 写入锁、版本检查和备份目录。另一个页面保存之后，旧版本会被拒绝；页面保留草稿，重新加载前请记录修改。
- 环境配置备份可能包含凭证，保存在 `data/admin/reply-backups/`，不要公开或提交该目录。

“测试当前填写配置”使用当前草稿及保留的凭证，不会保存配置；测试通过也不表示客服进程已使用新值。结果分为验证通过、部分验证、验证失败，返回固定提示，不回传上游响应中的凭证或业务数据。

| 服务 | 验证范围 |
|---|---|
| 对话模型 | 认证和模型列表核对，不执行对话生成；不支持模型列表时显示部分验证，不认定密钥有效 |
| FastGPT | 一次知识库搜索，可能产生一次检索调用；搜索结果不会返回到页面 |
| GeWe | 查询实例在线状态，不发送消息、不修改回调 |
| 飞书 | 应用凭证认证和表格列表访问，不执行同步、附件下载或写入表格 |

模型列表接口参照 [DeepSeek 官方文档](https://api-docs.deepseek.com/api/list-models/)，知识库搜索参照 [FastGPT 官方接口说明](https://github.com/labring/FastGPT/blob/main/document/content/openapi/dataset.mdx)，表格访问参照 [飞书官方接口文档](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table/list)。本项目的 GeWe 在线查询沿用已有客户端端点。

### 运行状态

侧栏选择“运行状态”，或访问 `/admin/#status`。首次加入运行状态模块后，需要重启一次 Windows 服务并重新登录，原管理员密码继续有效。

- **服务状态**：展示当前 Uvicorn 进程的启动时间、运行时长和调度器是否仍在运行。时间以北京时间显示；时长按单调时钟计算，不受系统时间校准影响。
- **本地检查**：只读检查商品数据库和任务库。进程已完成启动、调度器仍在运行且两库可读取时，显示“本地服务正常”；配置读取异常也会提示需要检查。这不代表外部模型、微信或飞书连接已通过验证。
- **待重启配置**：只统计“回复策略”和“模型与连接”页面开放的参数，包括密钥变化。按页面显示数量并提供跳转，不返回参数值或密钥；不统计未开放的 `.env` 参数。配置无效或无法读取时显示未知，而非零项。
- **任务分布**：统计任务库保留的全部历史与当前任务，使用真实六种状态：等待静默、处理中、人工接管、已回复、已关闭、已阻断。未来或未知状态仅汇总计数，不显示原始内容。库缺失、损坏或被锁定时数量显示“—”；页面不会创建或初始化数据库。
- **最近异常**：仅采集本次进程启动后的客服模块和 HTTP 服务 ERROR / CRITICAL 记录，保留最近 50 条分类摘要及时间，并显示本次启动累计条数。采集器不保留原始日志正文、插值参数、异常堆栈、客户 ID 或消息内容；不会读取历史日志文件。重启后清空。需要详细原因时在服务器本机按时间查看日志。
- 任务处理异常可能退回等待状态后重试；“已阻断”不等于“执行失败”。异常条数是日志记录数，并非失败任务数，历史异常也不直接决定当前服务状态。
- 支持手动刷新和每 15 秒自动刷新开关。在后台页面内切换后保留开关选择；离开运行状态页、切换浏览器到后台或退出时暂停刷新，返回后重新读取。请求失败时保留上次成功数据并明确提示过期状态。
- 状态 API 使用现有管理员会话保护和 `Cache-Control: no-store`。刷新只读取统计，不调用外部服务、不领取任务、不改变任务状态、不发送微信消息。首版继续通过管理员 PowerShell 重启服务。

### 修改记录与备份恢复

侧栏选择“修改记录与恢复”，或访问 `/admin/#history`。新增模块需要重启一次正式服务，已有密码继续有效。前端已构建时无需再次安装 pnpm。

1. 查看修改记录：展示后台保存或恢复的时间、页面范围、修改字段和完成结果；记录不保存字段值、群 ID、话术正文或密钥。
2. 在备份区域选择“群策略”或“环境配置”，点击“预览差异”。备份时间是快照生成时间，内容是那次操作**之前**的配置。
3. 核对普通参数的前后值和密钥替换提示。密钥仅显示是否已配置；保留与替换均不回传内容。
4. 确认恢复。其他配置页面有未保存草稿时，可以预览但不能确认；先保存或放弃草稿再操作。恢复成功后，受影响配置页重新读取文件。
5. 群策略在下一次读取时生效；环境配置需重启客服服务。若需撤销恢复，在备份列表选择本次恢复前新生成的备份，再预览并恢复。

恢复范围：

| 文件 | 页面恢复范围 | 保留内容 |
|---|---|---|
| 群策略 TOML | 授权群名单及顺序、全局处理开关、页面开放的群规则、安抚话术模式和文案 | 当前文件的全局未开放字段、仍保留群的未开放字段和既有注释；重新加入的群只恢复页面支持的字段 |
| `.env` | 六项回复运行参数、九项连接参数、四项密钥 | 当前文件其他参数（包括保险库密钥和 FastGPT 兼容密钥）、注释、新旧别名和换行 |

- 页面恢复是**可管理字段恢复**，不等于原文件字节级覆盖。备份缺少某个可管理参数时，该参数恢复为项目默认值；旧、新别名和重复赋值一起更新。
- 服务环境变量覆盖的参数如存在恢复差异，会阻止整次环境配置恢复；不会只恢复部分字段。先在实际服务环境中处理覆盖项。
- 当前文件语法损坏时，页面不能安全保留其他配置，需在服务器本机先修复。格式正确但数值无效的开放参数，可以从有效备份恢复。备份中格式无效、地址携带认证内容或公开参数引用密钥时，不允许恢复。
- 预览不写入文件、备份或修改记录。确认时重新检查当前文件版本、备份完整性及恢复条件；预览后有变化，会拒绝旧预览，要求重新预览。
- 恢复沿用与保存相同的进程内锁、原子替换和最终内容检查。每个文件单独恢复，不同时恢复 TOML 与 `.env`。不自动重启服务，不主动发送微信消息；恢复的群规则会被正常业务处理流程使用。
- 列表每页 20 条，可以继续加载更早记录和备份。已有标准命名、内容校验通过的历史备份可使用；不补造旧版本的修改记录，也不记录人工直接编辑文件的操作。
- 记录库默认是 `data/admin/history.db`，随管理员凭证父目录变化。记录在重启后保留；首次保存前，读取空记录不会创建数据库。
- 写入修改记录或备份失败时，拒绝修改配置。先持久化操作意图，再写备份和配置；配置已写入但完成记录未确认时，页面提示“结果待核对”，记录保留，不将保存成功伪报为失败。未完成操作的备份标识可能尚未对应真实备份文件。
- 群策略备份上限为 16 MiB，环境配置备份上限为 2 MiB；只接收标准备份名及目录内的普通文件，拒绝路径跳转、链接文件和内容校验不符的备份。页面不提供原始备份下载。
- 历史和备份接口使用管理员会话、预览与恢复请求还需要同源及 CSRF 校验；返回 `Cache-Control: no-store`。备份原文件可能包含凭证，仍应留在服务器管理目录内。

## 聊天记录

入口为侧栏“聊天记录”，也可直接访问 `http://127.0.0.1:5330/admin/#chats`。

- 按已留存的群 ID 聚合，同一群改名后仍是一个会话，列表使用最近留存的非空群名称。已从授权配置中移除的群，其历史记录仍可查看。现有归档只覆盖当时已配置的群，私聊不会展示。
- 右侧按消息接收／写入顺序显示客户、客服与机器人消息，以北京时间显示日期和时间。支持引用摘要、提及标记和消息详情；未留存昵称时使用发送者 ID。不补造原文中已经移除的 @ 内容，不标记送达或已读状态。
- 最新记录每批 50 条，“加载更早记录”向前翻页并保留阅读位置。历史翻页使用固定快照，新增消息通过“刷新聊天”增量读取；超过一批时可继续加载。筛选支持正文、引用、附件名称、身份、类型和日期，日期首尾均按北京时间包含。
- 自动刷新默认关闭。打开后每 15 秒读取新消息；切换页面或浏览器标签页进入后台时暂停，在返回时恢复。在阅读旧消息时不强制滚动到底部。
- 本地仍存在的常见图片可预览，文件可下载。入站图片只随最近 60 条上下文窗口保存，文字归档不会跟随清理；旧图片可能只剩消息占位。语音、视频和卡片原件未本地留存时显示类型及可用摘要。缺失附件不会自动重新下载。
- 消息正文以普通文本显示。微信媒体 XML 只提取标题和描述，不输出 CDN 地址、AES 参数及原始 metadata。预览／下载使用受管理员会话保护的专用接口；路径限制在配置的附件目录内，只允许识别出的普通图片内联，其余作为附件下载。
- 只读取服务启动配置中的 `CHAT_LOG_DB_PATH`（默认 `data/chat-log.db`）及本地附件索引，不创建、迁移或改写聊天数据库。归档开关关闭时仍可读历史；文件缺失、损坏或不可读时显示错误，不将异常当作零条记录。
- 查询使用带同源及 CSRF 校验的 POST 请求，避免将消息搜索词放入请求 URL。结果和附件均禁止缓存。浏览记录不会发起客服回复、修改配置或创建修改记录。

本工作区已构建前端。新增接口需要在管理员 PowerShell 重启服务一次，管理员密码无需重新设置。

## 访问控制

管理 API 使用 HttpOnly、SameSite=Strict Cookie 会话，8 小时到期；修改请求还需要 CSRF 令牌，浏览器只接受同源请求。密码错误连续 5 次后，该来源地址暂时限流 60 秒。重启服务或重新设置密码会使原会话失效。

默认没有管理员密码：未初始化时只能看到设置说明，不能读取或修改群配置。公网登录必须使用 HTTPS，本机回环地址允许 HTTP。浏览器显示 `/admin/` 登录页不代表拥有配置读取权限。

局域网访问使用管理员 PowerShell 运行（网段和本机地址按实际情况填写）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\瀚思AI客服\scripts\enable_lan_access.ps1" -Network "192.168.2.0/24" -LocalAddress "192.168.2.73"
```

脚本备份并保留 `.env` 其他内容，设置 `ADMIN_LAN_HTTP_NETWORKS`，创建／更新 TCP 5330 入站规则，仅放行指定网段到本机指定地址，然后重启服务并检查健康状态。不会开启或关闭 Windows 防火墙，也不会改变网络类别。防火墙原本关闭时，新规则仅在之后启用防火墙时生效。

同网段机器访问 `http://192.168.2.73:5330/admin/`，使用原管理员密码。该 HTTP 登录例外默认关闭，只允许显式配置的 RFC1918 IPv4 网段；请求目标 IP 和实际客户端 IP 必须同时位于允许网段内。密码、会话、CSRF 及同源校验仍然保留。HTTP 在局域网内不加密，应仅用于可信局域网。地址由 DHCP 变化后需要更新配置和防火墙规则；多个网段可用逗号分隔配置。

5330 同时提供微信公网回调和媒体下载。公网反向代理建议只放行业务需要的路径：

```nginx
location = /api/wechat/callback { proxy_pass http://127.0.0.1:5330; }
location /v1/media/ { proxy_pass http://127.0.0.1:5330; }
location / { return 404; }
```

上述地址是示例，按服务器实际拓扑调整。管理员入口通过本机、SSH 转发或受保护的 HTTPS 管理入口访问；不要把公网穿透地址用作未受保护的管理入口。现有回调代理头配置仍需保留。
