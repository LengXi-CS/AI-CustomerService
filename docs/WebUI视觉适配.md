# Handsin WebUI 视觉适配

本项目以主目录的 `Handsin瀚思 Web UI 视觉规范.zip` 为视觉来源，使用其中 `index.html`、`styles.css` 和品牌资源，适配管理员工作空间。

## 统一设计参数

| 用途 | 参数 |
|---|---|
| 品牌文字、图标、链接 | Trust Teal `#1D8F87` |
| 主动作 | Soft Aqua `#B5EBE6` → Clean Mint `#8DE0DA`，搭配深色文字 |
| 当前导航、轻提示、机器人消息 | Care Fog `#E6F8F7` |
| 辅助暖色 | Warm Blush `#F7E5DE`，用于少量身份标记和提示 |
| 正文与标题 | Soft Ink `#1A1A1A`，正文 `#525957`，辅助信息 `#767D7B` |
| 内容容器 | 白色卡片、16px 圆角、7% 黑色边框，默认无阴影 |
| 品牌展示、弹窗 | 24px 圆角；按钮和状态标签采用胶囊形 |
| 页面栅格 | 最大宽度 1152px，桌面内边距 40px，模块间距 16/24px |
| 字体 | Noto Sans SC → PingFang SC → Microsoft YaHei → sans-serif |
| 交互反馈 | 200ms 颜色、300ms 状态；可见键盘焦点和减少动态效果支持 |

排版根据管理员界面的信息密度调整：登录页品牌标题最大 48px，功能页标题 36px，卡片标题 18–20px，正文和表单 14px，辅助信息 12px。手机端主标题为 28px。字体使用本地回退，不依赖外部字体服务。

## 应用范围

- 登录页复用规范包内的正式 Logo 与森林图片，采用薄荷色叠层和白色登录卡片。
- 群管理、回复策略、模型与连接、运行状态、修改记录与恢复、聊天记录使用统一的白色导航、卡片、控件、提示与状态语言。
- 客户消息使用白色气泡，机器人消息使用雾青气泡，客服身份以少量暖粉区分。保留引用、附件、历史翻页和筛选功能。
- 弹窗限定在视口内，长表单在内容区滚动；手机端切换为顶部品牌区、横向导航和单列表单。聊天列表与时间线分别保留滚动区域。
- 保留现有认证、局域网访问、配置草稿、确认保存、恢复及只读聊天查询行为。

## 源文件与维护

- `webui/src/brand-theme.css`：品牌 tokens、Element Plus 样式和各页面的视觉适配。
- `webui/src/style.css`：页面结构与响应式布局，颜色统一引用品牌 tokens。
- `webui/src/assets/handsin-logo.png`、`handsin-forest.jpg`：规范包原始资源，未重绘或修改图片内容。
- `webui/src/App.vue`：品牌入口、登录区和工作空间导航。

修改后执行 `scripts/build_webui.ps1`。构建产物由现有后端提供，本次仅更新前端；刷新浏览器即可加载新的资源，无需重启客服服务。

视觉与交互检查使用独立临时服务和虚构数据，覆盖六个页面、登录、弹窗、保存确认、备份预览、图片展示及 390/768/1024/1440px 宽度，不读取真实聊天内容、不触发客服回复。
